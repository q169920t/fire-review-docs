# 開發流程：怎麼跟 Claude 下指令

不用學 git 指令，用平常說話的方式告訴 Claude 就好。

| 階段 | 怎麼說 | Claude 會做什麼 |
|---|---|---|
| 開始一次改版 | 「接續 fire-review-docs。先抓 GitHub 最新版，再依照剛剛討論的規格修改。」 | 從 GitHub 下載最新程式（pull），照規格修改，放到你電腦試用 |
| 確認沒問題 | 「測試沒問題，存檔上傳。」 | 存一個版本紀錄並上傳（commit + push），**還不會推給同事** |
| 發布給同事 | 「發布 v1.4，更新說明：……」 | 建立正式版本（Release），同事打開程式時會收到更新提示 |
| 出問題 | 「v1.4 有問題，同事那邊先退回 v1.3。」 | 把正式版本退回上一版 |
| 查紀錄 | 「列出最近 5 次改了什麼。」 | 用白話整理版本紀錄 |

## 小習慣
- 一個對話只處理一件事，做完存檔後，下一個功能開新對話。
- 想讓 Claude 以後都遵守的規則，說「把這條加進 CLAUDE.md」。
- 模板、系統設定.json、案件資料都留在 Google 雲端硬碟，不會上傳到 GitHub。
