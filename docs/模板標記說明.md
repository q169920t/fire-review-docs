# 模板標記說明

在 Word 模板裡用大括號寫標記，產出時會自動換成案件資料。

| 寫法 | 意思 |
|---|---|
| `{工程名稱}` | 帶入欄位內容 |
| `{□新建}` | 勾選框：有勾印 ■新建，沒勾印 □新建 |
| `{□畫面名稱=文件印的字}` | 畫面上顯示「畫面名稱」，文件上印「文件印的字」 |
| `{□有-建照申請書}{□無-建照申請書}` | 一組「有／無」 |
| `{□}` | 只用在資料檢查表的表格裡（有／無／不須） |
| `{列:13}` | 資料檢查表第 13 項不是「不須」，才保留這一行 |
| `{列:□變更使用}` | 有勾「變更使用」才保留這一行 |
| `{列:3,□變更使用}` | 逗號：兩個條件都要符合 |
| `{列:□變更使用\|□室內裝修}` | 直線：符合其中一個就保留 |
| `{序}` | 依保留下來的順序自動編號（1、2、3…） |

- 條件標記放在那一行的最前面最清楚；整列內容都被刪掉時，表格的那一列也會移除。
- 大括號要成對，裡面不要多打空格；「模板與版本」頁會列出標記錯誤。
