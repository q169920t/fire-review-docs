# 消防審勘文件管理

消防審勘文件的免安裝桌面工具：依案件類別套用 Word 模板產出文件、用印檢查表、掃描檔改名與出錯檢查。

## 開始使用（exe 版，建議）
1. 到 [Releases](https://github.com/q169920t/fire-review-docs/releases/latest) 下載 **FireReviewDocs.exe**，放在自己電腦任何位置（可以改名，例如「審勘文件管理.exe」）。
2. 第一次打開時，Windows 可能顯示「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。
3. 程式會自動找到 `G:\我的雲端硬碟\##歌珊\審勘文件系統`；找不到時會請你選一次，之後會記住。
4. 有新版時，畫面上方會出現「立即更新」，按下去就會更新。

需要 Windows 10 或 11（內建 Microsoft Edge WebView2）。

## 瀏覽器版
用 Edge 或 Chrome 開啟 `app/審勘文件管理.html`，選擇「審勘文件系統」資料夾。

## 資料不在這裡
案件資料、模板、常用資料都存放於公司 Google 雲端硬碟的「審勘文件系統」資料夾，**不會**上傳到此 repository。
